# ⏱ 多计时器 - 分组版

一个支持分组管理的多计时器网页应用，可以创建多个分组，每组内添加多个计时器，具有搜索、预警和到时提醒功能。

## 🌐 在线访问

**直接访问**: https://timer-groups.netlify.app

无需下载，直接在浏览器中打开即可使用！

## ✨ 功能特性

### 📦 分组管理
- **新建分组**：创建新的计时器分组
- **分组命名**：点击分组名称可以重命名
- **删除分组**：删除整个分组及其所有计时器
- **添加计时器**：每个分组内独立添加计时器
- **灵活数量**：每组计时器数量自由增减

### ⏱ 计时器状态
每个计时器根据当前状态自动显示不同样式：
- ⚠️ **即将到时**：橙色边框提示
- ✅ **已到时**：红色边框 + 脉冲动画
- 📊 **正在计时**：普通样式

组内计时器按状态自动排序：即将到时 > 正在计时 > 已到时

### ⚙️ 可配置选项
- **目标时间**：设置计时器的目标时间（分:秒）
- **提前提醒**：设置提前多少时间进入"即将到时"状态（精确到秒）
- **声音提示**：开关提示音功能

### 🔍 搜索功能
- 实时搜索计时器名称
- 模糊匹配，大小写不敏感
- 搜索时自动隐藏无匹配结果的分组

### 💾 数据持久化
- 所有数据自动保存到浏览器本地存储
- 页面刷新后自动恢复所有状态
- 运行中的计时器在页面关闭期间的时间会被正确计算

### 🔔 语音提示
到时自动语音播报：`（组名）组（计时器编号）号时间到`

## 📖 使用说明

### 创建分组
1. 点击「+ 新建分组」按钮
2. 分组会自动创建并显示

### 添加计时器
1. 在目标分组中点击「+ 添加计时器」按钮
2. 计时器会添加到该分组中

### 重命名
- **分组名称**：点击分组标题进行重命名
- **计时器名称**：点击计时器上的名称标签进行重命名

### 计时器操作
- **▶ 开始**：开始倒计时
- **⏸ 暂停**：暂停计时
- **↺ 重置**：重置计时器
- **×**：删除计时器

### 设置
- **目标时间**：设置倒计时的总时长
- **提前提醒**：设置提前多久进入"即将到时"状态

## 🎯 主要特性详解

### 分组排序
- 每个分组内的计时器按状态自动排序
- 即将到时的计时器排在最前面
- 正在计时的排在中间
- 已到时的排在最后

### 响应式设计
- **桌面端**：计时器自动填充可用空间
- **平板端**：自动调整列数
- **移动端**：单列显示

### 无障碍支持
- **ARIA标签**：支持屏幕阅读器
- **键盘导航**：支持键盘操作
- **减少动画**：支持用户的减少动画偏好

## 🔧 自定义配置

### 修改默认值
在 `index.html` 中修改以下变量：
```javascript
let targetSeconds = 60;     // 默认目标时间（秒）
let warningSeconds = 30;    // 默认提前提醒时间（秒）
let soundOn = true;         // 默认声音开关
```

### 修改样式
在 `<style>` 标签中修改CSS变量：
```css
:root {
  --bg: #0f1117;           /* 背景颜色 */

```
